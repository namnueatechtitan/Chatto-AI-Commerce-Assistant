# Chatto Repository Guidance

- This repository is currently in Phase 2.
- Only build Phase 2 scope.
- Do not implement Phase 3 or commerce features yet.
- Do not implement payment, order, subscription, or inventory features yet.
- Do not implement real LINE webhook logic until Phase 2.2.
- Do not implement real OpenAI or RAG logic until Phase 2.3 and Phase 2.4.
- Keep modules clean and isolated.
- Update docs when structure changes.
- Use TypeScript strictly.
- Prefer simple, readable code.
- Every module must have clear responsibility.
